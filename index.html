video-captions

Give any AI coding agent a video and it transcribes the speech locally and burns in accurately-timed captions. No API key. Nothing uploaded. Offline after a one-time model download.

Install into every agent you have
bash 
$ curl -fsSL https://raw.githubusercontent.com/katareayush/video-captions/main/install.py | python3
Usage

Describe it, don't configure it

With no styling it uses a clean, minimal look. Describe what you want and the agent translates it into flags — pass only what you imply, the rest stays at the default.

You sayThe agent runs
(nothing)clean white subtitles, bottom-centre
"big bold yellow captions at the top"--pos top --size large --weight bold --color yellow
"make it a viral TikTok caption"--word-by-word
"3 lowercase words on a rounded pill"--preset
"it's in Hindi, give me English subs"--translate
"just give me an SRT file"--export srt --no-burn
"caption every video in this folder"<folder path>
"a few words were wrong"--model medium --context "names, jargon"

No agent in the loop? Setup puts a video-captions launcher on your PATH, so every flag above works straight from a terminal too.

Install

One command covers it

The command in the hero detects every agent on your machine and installs into each. These are the only cases that differ.

How it works

A small, local pipeline

video  ─►  faster-whisper   ─►  words + timestamps
                                    │
                    build captions  ─►  synced, wrapped, positioned lines
                                    │
                         ffmpeg  ─►  <name>_captioned.mp4
Requirements
  • Python 3.9+ — the orchestration runtime.
  • ffmpeg with subtitle support — setup installs a compatible build automatically on macOS; Windows & Linux ffmpeg already include it.
  • No API key, no account, no network after the one-time model download.
