Claude Code Plugin

video-captions

Give Claude a video and it transcribes the speech locally and burns in accurately-timed captions. Fully offline. Cross-platform. Describe the style in plain words.

Get started View on GitHub
What it does

Accurate captions, on your machine

Runs entirely locally

Transcription via faster-whisper, rendering via ffmpeg. No API key, no upload. After a one-time model download it works fully offline.

Well-timed & readable

Word-level timestamps become short lines synced to the speech — no wall of text, no flicker, and they fit any aspect ratio.

Describe the look

Minimal by default. Say "big yellow captions at the top" and Claude maps it to the right styling — no rigid presets.

Viral word-by-word

The TikTok / Reels karaoke look — a few words at a time with the spoken word highlighted, driven by real word timestamps.

Subtitles, translation & batch

Export editable .srt/.vtt, translate any language to English, fix a word and re-burn, or caption a whole folder at once.

Windows & macOS

Pure Python orchestration, no Homebrew or bash assumptions. Setup installs a subtitle-capable ffmpeg for you.

Install

Two lines in Claude Code

1 — add the marketplace & install the plugin
/plugin marketplace add katareayush/video-captions
/plugin install video-captions@katareayush
2 — then just ask, in any project
add captions to demo.mp4

The first run installs its dependencies and downloads the Whisper model once (~150 MB). Everything after is offline.

Usage

Describe it, don't configure it

With no styling it uses a clean, minimal look. Describe what you want and Claude translates it into flags — pass only what you imply, the rest stays at the default.

You sayClaude runs
(nothing)clean white subtitles, bottom-centre
"big bold yellow captions at the top"--pos top --size large --weight bold --color yellow
"make it a viral TikTok caption"--word-by-word
"it's in Hindi, give me English subs"--translate
"just give me an SRT file"--export srt --no-burn
"caption every video in this folder"<folder path>
"a few words were wrong"--model small
Private by design

Nothing leaves your machine

Your own Claude

It's just a plugin — it runs inside your Claude Code and uses your own model. No third-party service sits in the middle.

Local compute

Transcription and rendering happen on your computer with faster-whisper and ffmpeg. Your videos are never uploaded anywhere.

No keys, no account

No API key, no sign-up, no server. After the one-time model download it runs fully offline.

How it works

A small, local pipeline

video  ─►  faster-whisper   ─►  words + timestamps
                                    │
                    build captions  ─►  synced, wrapped, positioned lines
                                    │
                         ffmpeg  ─►  <name>_captioned.mp4
Requirements
  • Python 3.9+ — the orchestration runtime.
  • ffmpeg with subtitle support — setup installs a compatible build automatically on macOS; Windows & Linux ffmpeg already include it.
  • No API key, no account, no network after the one-time model download.
